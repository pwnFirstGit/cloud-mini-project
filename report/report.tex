\section{Task 1 --- Teacher labelling and cleaning}
\subsection*{Setup}
\begin{itemize}
\item Cluster \texttt{cs3081} from \texttt{cluster/k3d.yaml}; SeaweedFS in namespace \texttt{data}; buckets \texttt{datasets} and \texttt{models}.
\item \texttt{commands\_pool.jsonl} (3,000 commands, C0001--C3000) uploaded to \texttt{s3://datasets/}.
\item Prompt in \texttt{prompts/teacher\_prompt.txt}: exactly four keys (\texttt{intent, date, time, place}), eight intents, copy-exactly slots, shortest phrase, \texttt{null} if unmentioned, never invent, output only JSON.
\item Worker (\texttt{worker/}): reads \texttt{SHARD\_INDEX} / \texttt{SHARD\_COUNT}; takes lines whose 0-based line number mod 2 $=i$; writes \texttt{\{id, text, teacher\_raw\}} to \texttt{shard-$i$.jsonl} in \texttt{s3://datasets/teacher/}.
\item Sharding: embarrassingly parallel, deterministic, no coordination; each shard is an independent S3 object; \texttt{clean.py} merges both shards in id order, so re-running it reproduces the same checksum.
\end{itemize}

\end{itemize}

\subsection*{Distillation explanation}
\begin{itemize}
\item \textbf{Sequence-level:} student is trained on the teacher's generated sequences (the full JSON output) as targets.
\item \textbf{Logit-based:} student is trained to match the teacher's token-level output distribution (soft probabilities over the vocabulary at each step).
\item \textbf{Why logit-based is impossible here:} Ollama (and the HF text-generation path used) returns text only, no teacher logits.
\item \textbf{One real limitation:} student only ever sees the teacher's greedy outputs, so it inherits the teacher's errors and formatting quirks and cannot recover token-level uncertainty.
\end{itemize}
\subsection*{Issues and corrections}
\begin{itemize}
\item \textbf{Training v1 loss was broken} (epoch 1: 141.55, epochs 2--3: exactly 0.0; transformers 5.20.2 fault) and eval was 0\% on every metric. Correction: pinned torch 2.5.1 + transformers 4.47.1, masked pad labels with -100 --- loss became sane (3.23 $\to$ 0.58).
\item \textbf{Eval still 0\% despite good loss.} Root cause: greedy regex \texttt{\{.*\}} in \texttt{predict.py} grabbed through the last \texttt{\}}, including garbage after the valid JSON (model never learned EOS). Correction: non-greedy \texttt{\{.*?\}} in \texttt{predict.py} and \texttt{service/app.py} --- student then scored 100/67/72/82/77/29.
\item \textbf{\texttt{make train SUBSET=50} loss on Mac was not credible} (3263 $\to$ 0, grad.\ norm NaN) because the Mac has transformers 5.20.2; repo pins 4.47.1, which gives the sane losses above.
\end{itemize}

\section{Task 5 --- Subnets and NACL}
\subsection*{Subnets}
\begin{itemize}
\item From 10.20.0.0/16, largest first, smallest prefix that fits: app 10.20.0.0/22 (usable 10.20.0.1--10.20.3.254, 1,022 hosts); public 10.20.4.0/24 (254); data 10.20.5.0/25 (126); management 10.20.5.128/27 (30). Full table with broadcast addresses in \texttt{network/subnets.md}.
\end{itemize}
\subsection*{NACL rules}
\begin{itemize}
\item Inbound: rule 100 denies 198.51.100.0/24 before rules 120/130 allow TCP 80/443 from anywhere; TCP 22 only from the management subnet (rule 110); ephemeral replies (1024--65535) only from the app subnet (rule 140).
\item Outbound: TCP 8000 only to the app subnet (rule 110); rule 115 denies all other traffic to 10.20.0.0/16; ephemeral replies to clients (rule 120); 198.51.100.0/24 denied outbound at rule 100.
\item Check: \texttt{nacl\_sim.py --check} on the six sample packets passes 6/6 (100\%).
\end{itemize}
\subsection*{Explanation}
\begin{itemize}
\item A stateless NACL has no memory of connections, so unlike a stateful security group it cannot infer that a reply belongs to an allowed request --- every packet, including replies, is checked on its own, so reply traffic needs its own rules (ephemeral ports 1024--65535).
\item Rule order matters: lowest number is checked first, so the deny for 198.51.100.0/24 (rule 100) fires before the allow rules for 80/443 (120/130) --- a deny only works if its number is lower than the allow it must override.
\end{itemize}
\subsection*{Issues and corrections}
\begin{itemize}
\item \textbf{First NACL missed the outbound deny} for the rest of 10.20.0.0/16. Correction: added rule 115 (deny all to 10.20.0.0/16) between the 8000 allow and the reply allow; re-checked 6/6.
\end{itemize}
